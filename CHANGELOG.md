# Changelog

## 1.1.0 — 2026-11-15

### Исправлено

- Поворот, тень и размытие групп теперь корректно попадают в SVG/PNG-экспорт, HTML-просмотр и миниатюры.
- Обводка фрейма отображается на холсте так же, как в экспорте.
- `Ctrl+S` перезаписывает уже открытый или сохранённый файл без повторного диалога.
- Добавлено «Сохранить как…» (`Ctrl+Shift+S`); отмена диалога больше не выдаётся за успешное сохранение.
- При переполнении localStorage появляется предупреждение вместо молчаливой потери автосохранения.

### Улучшено

- Плагины при повторном запуске заменяют свои пункты меню и кнопки, а не дублируют их.
- API плагинов работает с вложенными группами: `update`, `remove`, `duplicate`.
- Добавлены README, лицензия, скриншот и `.gitignore`.

## 1.0.0

- Первая версия: холст, слои, страницы, фигуры, текст, градиенты, группы, экспорт, плагины `.empl`.
